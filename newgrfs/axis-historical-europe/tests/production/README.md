# Transport and stockpile-persistence fixture

This is a destructive **disposable-world test**, not a campaign GameScript.
It builds industries, roads, stations and trucks in a new flat 256² 1860 map
generated by `production_test.py`; it never loads an existing campaign save.

From `newgrfs/axis-historical-europe/`, run using the tested build environment
and a separate JGRPP 0.73.4 engine
under this project's ignored `.work/` directory:

```powershell
.venv/Scripts/python.exe production_test.py --engine-directory ABSOLUTE_PATH_TO_DISPOSABLE_ENGINE
```

Add `--resume` to replay the reload phase from this fixture's existing saved
checkpoint and initial log, without rebuilding the upstream transport scene.

The runner requires the already compiled fork GRF and OpenGFX in the isolated
engine, as described in the main README. It binds localhost, starts an idle
test company, captures logs, saves a checkpoint, terminates that process, then
starts another process loading that checkpoint. Only its own child processes
are terminated. The fixture can take several real minutes because newly funded
industries must finish construction and trucks must physically move their loads.

Routes: coal mine → coke oven; iron-ore mine → blast furnace; blast furnace →
historical steelworks (pig iron); coke oven → steelworks (coke); steelworks →
metal workshop (steel). The upstream processors retain AXIS's partial-input
recipes; the historical steelworks must require both inputs.

The test intentionally force-enables suitable **default trucks** in the 1860
test company with the supported `GSEngine.EnableForCompany` API. This isolates
industry mechanics without installing or modifying any transport NewGRF.
It is **not evidence of historical vehicle availability or campaign refits**.

Pass conditions:

1. Physically transported pig iron reaches the steelworks while the coke
   delivery truck remains stopped. No steel production/pickup is observed.
2. The game is saved with pig iron present and coke absent.
3. A new JGRPP process loads the disk save; industry IDs and exact input
   stockpiles survive. The script state loads rather than rebuilding the scene.
4. The coke truck starts. Steel is produced and physically delivered to the
   metal workshop. Completed-month steel/slag production has the 3:1 ratio,
   and leftover pig iron matches the integer-batch remainder.

`production-result.json` records the executed outcome; a written fixture alone
is not a passing result. Full logs and the checkpoint stay under
`.work/production-test/`. The original GRF remains unchanged by this test.
