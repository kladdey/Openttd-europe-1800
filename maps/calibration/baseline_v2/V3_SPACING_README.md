# Europe 1800 - V3 spacing-cleaned local test

This is a **13-town candidate**, derived from the 15-town local expansion test. It is not a full-map geographic correction.

- Original five V2 control cities are unchanged: London, Dublin, Paris, Berlin, Stockholm.
- Versailles and Boulogne are **deferred, not deleted from the 600-town master catalogue**, because they fall within 15 tiles of another Paris-area settlement in V2. Boulogne's identity remains ambiguous.
- Oxford, Cambridge, Reading, Kilkenny, Waterford, Potsdam, Brandenburg and Magdeburg are retained at their previous local test coordinates.
- Spacing policy: <15 tiles omit/review; 15-30 review; >=30 provisionally acceptable. Historic significance and corrected coordinates can override this heuristic.
- German town orientations, exact British/Irish placements and all other geography still require verification; the original coordinate source is not geographically reliable.
- Do not layer-import into an already populated scenario; test in a fresh empty scenario.
- **No original data, calibration files or playable scenario modified.**
