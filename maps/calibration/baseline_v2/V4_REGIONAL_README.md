# V4 - 40-town regional expansion (EXPERIMENTAL)

Created from the accepted V2 five-city anchors and V3 13-town spacing-cleaned test. **No original files or playable scenario overwritten.**

**40 total:** 13 V3 towns unchanged, 27 new towns added (England 7, Ireland 5, France 8, Germany/Baltic 7).

The 27 new coordinates use a local translation of the *old unverified 600-town source* relative to their regional V2 anchor. This preserves source-local offsets, but **does not prove real-world geography or land/sea placement**. The map is rotated/isometric; do not interpret x/y as longitude/latitude. Visually test every region on the original heightmap before accepting or importing in a production scenario.

Spacing: all 40 towns are at least 30 tiles apart (Euclidean distance in normalized game coordinates). Greenwich was **deferred**, not removed from the 600-town master catalogue: 16.6 tiles from London. Versailles and Boulogne remain deferred from V3.

**Unresolved:** Potsdam/Brandenburg/Magdeburg orientation; Boulogne identity; Paris environs; whether the northern German and French towns fall on appropriate land and coastlines. Stockholm is unchanged; no Sweden extrapolation attempted.

Import into a **fresh empty test scenario** only. No scenario binary was edited. The 600-town catalogue remains the source of truth.

See `Europe_1800_40_city_V4_AUDIT.csv` for nearest-neighbour spacing.
