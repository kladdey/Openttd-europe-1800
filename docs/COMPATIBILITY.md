# Compatibility and asset policy

> Current project context: [status and limitations](PROJECT_STATUS.md). Game, NewGRF compatibility and installer release testing remain pending. FIRS 5.2.0 Temperate Basic is the intended industry setup; this work changes no NewGRF configuration.

Target game: OpenTTD JGR's Patch Pack v0.73.4 on Windows 11 x64.
Target scenario: 4096 x 4096 Europe heightmap, 1800-2025 campaign.

Candidate components, **not yet compatibility-tested**:
- Timberwolf's UK Trains
- Polish Rolling Stock Pack
- GETS German Extrazoom Trainset
- Timberwolf's Tracks
- FIRS Industries 5
- eGRVTS, Sailing Ships, Multi-SHARK
- Timberwolf's Stations, Industrial Stations Renewal

Pin exact versions only after testing. Do not redistribute third-party graphics, game scripts, maps, or executables without checking their respective licenses. The portable installer should not overwrite existing OpenTTD installs or saves.
