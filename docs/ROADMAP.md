# Development roadmap

## Phase 1 - Historical settlement data
- [ ] Audit existing provisional 249-settlement draft.
- [ ] Obtain licensed historical urban population datasets and document provenance.
- [ ] Collect 1800-era population values (census where available, estimates otherwise).
- [ ] Identify historical borders and names; retain modern identifiers.
- [ ] Expand to approximately 600 settlements and document uncertainty.

## Phase 2 - Map calibration
- [ ] Identify geographic bounds and projection of the 4096 x 4096 heightmap.
- [ ] Calibrate latitude/longitude to tile coordinates with control points.
- [ ] Validate coastlines, rivers and town placements.
- [ ] Confirm Scenario Editor town import schema in JGRPP 0.73.4.

## Phase 3 - Gameplay
- [ ] Select and compatibility-test historical UK, Polish and German train sets.
- [ ] Test FIRS 5, tracks, road vehicles, ships and stations.
- [ ] Tune town growth, starting economy and inflation.
- [ ] Test performance on 4096 x 4096 with ~600 towns.

## Phase 4 - Release
- [ ] Save and test playable .scn in JGRPP 0.73.4.
- [ ] Build safe Windows 11 portable installer for Toni.
- [ ] Document third-party asset licensing and download requirements.
- [ ] Publish checksums and reproducible release instructions.

**Status:** Planning / data acquisition. No complete playable scenario has been validated.
